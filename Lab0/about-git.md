1\. Чем ветка отличается от копии папки с проектом?

Ветка — это указатель на определённый коммит в общей истории Git. Она не копирует файлы физически, а позволяет вести параллельную разработку в одном репозитории и затем сливать изменения. Копия папки — это отдельный набор файлов, не связанный с историей.



2\. Что произойдёт с историей, если удалить папку проекта, но сохранить .git?

Вся история коммитов сохранится в папке .git. Можно восстановить файлы командой git checkout или git restore, так как Git хранит снимки всех версий.



3\. Зачем нужен Pull Request, если можно коммитить сразу в main?

PR позволяет проверить изменения перед слиянием, обсудить их, оставить комментарии и поймать ошибки. При командной работе это защищает main от непроверенного кода и документирует, кто и что менял.
